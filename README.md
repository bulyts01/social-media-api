# job4j_social_media_api

## О проекте

### Проект - пример разработки социальной сети, для наглядного примера серверной разработки на Java.


### Центральный процесс курса:

→ пользователь отправляет заявку в друзья

→ становится подписчиком

→ второй пользователь принимает заявку

→ создаётся дружба

→ оба пользователя становятся подписчиками друг друга

→ система отправляет уведомления

### Позже к этому процессу добавятся публикации, лента и переписка.
### Нам важно не просто реализовать набор CRUD-операций, а научиться отвечать на вопросы:

→ кто запускает процесс;

→ какое состояние меняется;

→ какие правила нельзя нарушать;

→ какие изменения должны быть атомарными;

→ что увидит клиент при ошибке;

→ как найти запрос в логах и трассах;

→ по каким метрикам понять, что процесс работает.

### Команда запуска приложения:

./mvnw spring-boot:run

### URL для отправки GET запроса:

http://localhost:8080/api/ping
